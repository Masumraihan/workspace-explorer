# File Explorer

A VS Code style file explorer built with Next.js, Redux Toolkit, and shadcn/ui.

## Prerequisites

- Node.js 18 or later
- npm (or yarn / pnpm / bun)

## Setup

Install dependencies:

```bash
npm install
```

## Running the app

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

## Features

- Browse files and folders in a collapsible tree
- Create new files and folders
- Rename files and folders via the three-dot menu
- Delete files and folders with a confirmation prompt
- State is managed with Redux Toolkit
